# Лабораторная работа 2

Программа создаёт базу данных `movies_rating.db` и загружает в неё фильмы, оценки, теги и данные пользователей из текстовых файлов.

## Требования

- Python 3
- SQLite 3 с командой `sqlite3`
- Bash

## Запуск

Из корневой папки репозитория выполните команду: `bash Task02/db_init.bat`

Скрипт создаст файл `db_init.sql`, выполнит его и создаст заполненную базу `movies_rating.db`. При повторном запуске таблицы удаляются и создаются заново.
