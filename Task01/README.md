# Структура файлов данных

В папке находятся файлы с данными о фильмах, пользователях, оценках и тегах.

## movies.csv

Файл содержит информацию о фильмах.

Столбцы:
- movieId — идентификатор фильма;
- title — название фильма;
- genres — жанры фильма.

В качестве разделителя используется запятая.

## ratings.csv

Файл содержит оценки фильмов пользователями.

Столбцы:
- userId — идентификатор пользователя;
- movieId — идентификатор фильма;
- rating — оценка;
- timestamp — время выставления оценки.

В качестве разделителя используется запятая.

## tags.csv

Файл содержит теги, которые пользователи добавляли к фильмам.

Столбцы:
- userId — идентификатор пользователя;
- movieId — идентификатор фильма;
- tag — текст тега;
- timestamp — время добавления тега.

В качестве разделителя используется запятая.

## users.txt

Файл содержит информацию о пользователях.

В каждой строке находятся:
- идентификатор пользователя;
- имя;
- фамилия;
- адрес электронной почты;
- пол;
- год рождения;
- профессия.

В качестве разделителя используется символ |.

## genres.txt

Файл содержит список жанров фильмов.

Каждый жанр находится на отдельной строке.

## occupation.txt

Файл содержит список профессий пользователей.

Каждая профессия находится на отдельной строке.
